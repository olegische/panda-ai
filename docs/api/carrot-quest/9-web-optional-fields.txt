Опциональные поля объектов
Многие поля Web API возвращают стандартизованные объекты.
Помимо стандартных полей объекта, которые возвращаются всегда, в описании некоторых объектов вы также найдете опциональные поля. Опциональные поля возвращаются в объекте только тогда, когда они явно запрошены (или метод "включает" их по умолчанию).

Это позволяет:

Сделать API удобным для разработчиков и не делать много лишних подзапросов, особенно в запросах, в ответ на которые приходят списке объектов.
Не нагружать излишне нашу систему выборкой опциональных полей, когда они не нужны разработчику.
В большинстве методов API опциональные поля можно запросить с помощью boolean параметров запроса вида include_{field_name}=true. В ряде отдельных старых методов "включение" опциональных полей делается с помощью других параметров, о чем будет указано в описании конкретного метода.
