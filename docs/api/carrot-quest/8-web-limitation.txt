Ограничения Web API
В целях защиты нашей системы от злоумышленников, установлены ограничения на выполнение некоторых запросов. На данный момент максимально допустимое количество запросов к WebAPI для одного API ключа — 60 в минуту.
При превышении лимита вы начнете получать в ответ на запрос ошибку 429 TooManyRequests и запросы не будут приниматься до тех пор, пока нагрузка не снизится. При значительном превышении ключ может быть автоматически заблокирован.

Если вам требуется массово обновлять данные пользователей, используйте специальные bulk-методы или формируйте очереди запросов, чтобы не превышать допустимое количество запросов. Также вы можете связаться с нашей поддержкой в чате, чтобы мы помогли вам найти эффективное решение.
