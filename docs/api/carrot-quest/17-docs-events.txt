События
Событие — это дейcтвие пользователя, которое вы считаете важным (например, совершил заказ, зарегистрировался, оплатил подписку, перешел на страницу с тарифами, посмотрел товар и т.д.).

Вы можете отправлять в нашу систему события с любым именем. События, начинающиеся с символа $, являются системными (с зарезервированными стандартными именами):

Коммуникации
События, связанные с авто- и ручными сообщениями.

Начал диалог в чате
Системное имя: $conversation_user_started.

Атрибут	Описание
$body	Текст сообщения (первые 255 символов)
$conversation_id	ID диалога
Отправлено сообщение
Системное имя: $message_sended.

Атрибут	Описание
$message_id	ID сообщения
$message_type	Содержит auto для автосообщений и manual для ручных сообщений
$message_name	Имя сообщения (только для автосообщений)
$type	Содержит тип сообщения (popup_chat, popup_big, popup_small, email)
Прочитано сообщение
Системное имя: $message_read.

Атрибут	Описание
$message_id	ID сообщения
$message_type	Содержит auto для автосообщений и manual для ручных сообщений
$message_name	Имя сообщения (только для автосообщений)
$type	Содержит тип сообщения (popup_chat, popup_big, popup_small, email)
Ответил на сообщение
Системное имя: $message_replied.

Атрибут	Описание
$message_id	ID сообщения
$message_type	Содержит auto для автосообщений и manual для ручных сообщений
$message_name	Имя сообщения (только для автосообщений)
$type	Содержит тип сообщения (popup_chat, popup_big, popup_small, email)
Перешел по ссылке в сообщении
Системное имя: $message_clicked.

Атрибут	Описание
$message_id	ID сообщения
$message_type	Содержит auto для автосообщений и manual для ручных сообщений
$message_name	Имя сообщения (только для автосообщений)
$type	Содержит тип сообщения (popup_chat, popup_big, popup_small, email)
Отписался от рассылки писем
Системное имя: $message_unsubscribed.

Атрибут	Описание
$message_id	ID сообщения
$message_type	Содержит auto для автосообщений и manual для ручных сообщений
$message_name	Имя сообщения (только для автосообщений)
$type	Содержит тип сообщения (popup_chat, popup_big, popup_small, email)
Закончил общение с лид-ботом
Системное имя: $chat_bot_finished.

Прочитал первое сообщение лид-бота
Системное имя: $chat_bot_read.

Ответил на первое сообщение лид-бота
Системное имя: $chat_bot_replied.

Отправлено первое сообщение лид-бота
Системное имя: $chat_bot_sent.

Прервал диалог с лид-ботом
Системное имя: $chat_bot_interrupted.

Попал в контрольную группу
Системное имя: $message_control_group.

Отправил письмо в spam
Системное имя: $message_spam.

Bounced – письмо не доставлено
Системное имя: $message_bounced.




Интернет-магазины
События, специфичные для сферы электронной коммерции.

Начал оформлять заказ
Системное имя: $order_started

Это событие происходит, когда пользователь перешел на первый шаг процесса чекаута.

Закончил оформлять заказ
Системное имя: $order_completed

Пользователь прошел все шаги процесса чекаута, заказ создан в системе магазина.

Атрибут	Описание
$order_id	ID заказа (внутренний)
$order_id_human	ID заказа человеческий (тот, который видит клиент)
$order_amount	Сумма заказа
Оплатил заказ
Системное имя: $order_paid.

Событие происходит, когда клиент оплатил заказ.

Атрибут	Описание
$order_id	ID заказа
Получил заказ
Системное имя: $order_closed.

Событие происходит, когда клиент получил заказ.

Атрибут	Описание
$order_id	ID заказа
Отменил заказ
Системное имя: $order_cancelled.

Событие происходит, когда клиент или магазин отменил заказ.

Атрибут	Описание
$order_id	ID заказа
$comment	Комментарий
Оформлен возврат
Системное имя: $order_refunded.

Событие происходит, когда клиент получил обратно оплату за заказ.

Атрибут	Описание
$order_id	ID заказа
Добавил товар в корзину
Системное имя: $cart_added.

Атрибут	Описание
$name	Название товара
$url	Ссылка на страницу с описанием товара
$amount	Цена товара в рублях. Целое число (если есть копейки, их необходимо округлить)
$img	Ссылка на картинку с товаром
Посмотрел корзину
Системное имя: $cart_viewed.

Все свойства в этом событии являются массивами.

Например, есть два товара с названиями А,B и ценами 10,20. Тогда в свойстве $name будет лежать A,B, а в свойстве $amount значения 10,20.

Атрибут	Описание
$name	Массив с названиями товаров
$url	Массив ссылок на страницы с описанием товара
$amount	Массив с ценами товара в рублях. Целое число (если есть копейки, их необходимо округлить)
$img	Массив со ссылками на картинку с товаром
Посмотрел товар
Системное имя: $product_viewed.

Атрибут	Описание
$name	Название товара
$url	Ссылка на страницу с описанием товара
$amount	Цена товара в рублях. Целое число (если есть копейки, их необходимо округлить)
$img	Ссылка на картинку с товаром
