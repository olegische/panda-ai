MESSAGE 1
PocketFlow — это современный фреймворк для создания мультиагентных систем, ориентированный на совместную работу человека и ИИ. Он разработан для упрощения проектирования, тестирования и развертывания сложных AI-ориентированных процессов, включая агентные рабочие процессы и Retrieval-Augmented Generation (RAG).

Основные особенности PocketFlow
	•	Модульные узлы (Nodes): Каждый узел представляет собой изолированный компонент с четким жизненным циклом, что упрощает управление состоянием и повторное использование кода.
	•	Декларативная оркестрация (Flow): Позволяет определять последовательность и логику взаимодействия узлов в виде декларативных потоков, облегчая понимание и поддержку систем.
	•	Иерархическая вложенность (Flow-as-Node): Поддержка вложенных потоков, где один поток может выступать как узел в другом, способствует созданию масштабируемых и модульных архитектур.
	•	Условная логика на основе действий: Обеспечивает явное управление логикой переходов между узлами, улучшая контроль над поведением системы.
	•	Интеграция с Pocket AI: Ассистент, использующий структуру PocketFlow для проектирования систем, ускоряет процесс прототипирования и развертывания.

Преимущества использования PocketFlow
	•	Минимальный код: Благодаря лаконичной архитектуре, PocketFlow снижает объем необходимого кода, облегчая разработку и поддержку.
	•	Гибкость и масштабируемость: Поддержка сложных паттернов, таких как агентные рабочие процессы и RAG, делает фреймворк подходящим для различных задач.
	•	Совместная разработка человек-ИИ: Фреймворк ориентирован на совместную работу, позволяя эффективно интегрировать человеческий вклад в процессы проектирования и разработки.
	•	Независимость от поставщиков: PocketFlow не привязан к конкретным вендорам, обеспечивая гибкость в выборе инструментов и платформ.

Применение

PocketFlow подходит для создания адаптивных и масштабируемых AI-систем, требующих четкой структуры и возможности быстрой итерации. Он может быть особенно полезен в корпоративных средах, где важно быстро разрабатывать и внедрять сложные AI-решения.

Если ты хочешь создавать агентов “на лету” в процессе решения задач с использованием OpenAI Assistant API, то PocketFlow (а не PocketBook — это, видимо, оговорка) действительно может сильно упростить такую архитектуру. Вот как и почему:

⸻

Чем поможет PocketFlow в твоем случае

1. Графовая модель исполнения

PocketFlow реализует поток исполнения как граф, где узлы — это агенты (или компоненты логики), а связи между ними задают последовательность, условия и ветвления. Это:
	•	позволяет динамически добавлять новых агентов в граф на основе состояния;
	•	упрощает контроль над логикой переключения между агентами.

2. Flow-as-Node

Ты можешь один “подпоток” превратить в узел, что позволяет создавать иерархии агентов или динамически вкладываемые подагенты.

Пример: Главный агент вызывает “переводчика”, а если перевод невозможен — создается “исследователь”, который сам ищет ответ и создает свои подагенты.

3. Условия и ветвления

Взаимодействие между узлами можно строить на условиях, например:
	•	Если ассистент не знает ответа → запускается генератор подсказок.
	•	Если пользователь выбрал конкретный тип запроса → создается агент-обработчик этого типа.

4. Интеграция с Assistant API

PocketFlow не привязан к конкретной LLM — ты можешь использовать узлы, которые оборачивают вызовы к OpenAI Assistant API, например:
	•	Один узел создает ассистента через API;
	•	Второй — создает тред и отправляет сообщение;
	•	Третий — обрабатывает run, анализирует tool_calls, динамически создает новых агентов и ветви графа.

⸻

Как это может выглядеть архитектурно

[UserInput] → [IntentDetector (LLM)] →
  ├─> [CreateAssistantIfNeeded]
  ├─> [RunThread]
  └─> [DispatchAgent(type=X)] → (вложенный Flow с подпроцессом)

В каждом узле может быть своя реализация запроса к Assistant API, и ты управляешь всем этим через декларативный YAML-файл или Python-конфигурацию.

⸻

Итог

Да, PocketFlow тебе поможет — он спроектирован как раз для мультиагентных сценариев с динамической логикой, особенно когда один агент может “порождать” других в процессе. Это даст тебе:
	•	простоту в проектировании;
	•	поддержку масштабируемой логики;
	•	гибкую интеграцию с OpenAI Assistant API.

2. Используемый узел openai-assistant (примитивный вариант)

Ты можешь реализовать свой узел на Python, вот набросок:

from pocketflow.node import Node

class OpenAIAssistantNode(Node):
    def run(self, state, context):
        from openai import OpenAI
        client = OpenAI(api_key="your-key")

        prompt = self.config["input"]["prompt"].format(**state)
        response = client.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": prompt}],
        )
        state["result"] = response.choices[0].message.content.strip()
        return state

Регистрируешь как плагин в PocketFlow или указываешь явно в YAML как Python-класс.

	3.	Можно легко добавить новый тип задачи — и появится новый агент.

2. Пример: мультиагентный поток в Python

from pocketflow import Flow, Node
from openai import OpenAI

# OpenAI API клиент
client = OpenAI(api_key="your-openai-key")


# Универсальный узел, вызывающий Assistant API
class OpenAIAgent(Node):
    def __init__(self, prompt_template):
        self.prompt_template = prompt_template

    def run(self, state, context):
        prompt = self.prompt_template.format(**state)
        response = client.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": prompt}]
        )
        result = response.choices[0].message.content.strip()
        print(f"Agent '{self.prompt_template[:20]}...' ответил: {result}")
        state["result"] = result
        return state


# Динамический выбор агента на основе первого запроса
def agent_router(state, context):
    intent = state["result"].lower()

    if "перевод" in intent:
        return OpenAIAgent("Переведи текст: {input}")
    elif "поиск" in intent:
        return OpenAIAgent("Найди информацию по запросу: {input}")
    elif "вычисление" in intent:
        return OpenAIAgent("Вычисли: {input}")
    else:
        return OpenAIAgent("Я не понимаю запрос: {input}")


# Главный поток
def create_flow():
    flow = Flow()

    # Узел 1: определить намерение
    detect_intent = OpenAIAgent("Определи тип задачи пользователя: \"перевод\", \"поиск\" или \"вычисление\". Вот запрос: {input}")
    flow.add_node("detect_intent", detect_intent)

    # Узел 2: запускается динамически на основе результата первого узла
    def dynamic_branch(state, context):
        dynamic_agent = agent_router(state, context)
        return dynamic_agent.run(state, context)

    flow.add_node("dynamic_agent", Node(run=dynamic_branch))

    # Последовательное соединение
    flow.set_entrypoint("detect_intent")
    flow.connect("detect_intent", "dynamic_agent")

    return flow

2. Логика обработки tool_call (серверный код)

from openai import OpenAI

client = OpenAI(api_key="your-key")

agents = {}

def handle_tool_call(tool_call):
    if tool_call.function.name == "create_agent":
        args = tool_call.function.arguments
        name = args["name"]
        goal = args["goal"]

        print(f"[+] Создание агента {name}: {goal}")

        # Создаем подагента на лету
        agents[name] = goal

        # Можно сразу запустить его
        response = client.chat.completions.create(
            model="gpt-4o",
            messages=[{"role": "user", "content": goal}]
        )
        result = response.choices[0].message.content
        print(f"[=] Результат от {name}: {result}")

        return {
            "tool_call_id": tool_call.id,
            "output": f"Agent '{name}' завершил задачу: {result}"
        }

def handle_tool_call(tool_call):
    args = tool_call.function.arguments
    name, goal = args["name"], args["goal"]

    print(f"[+] Создаем агента {name} с задачей: {goal}")

        "output": f"Результат от {name}: {result['result']}"

Шаг 2. Универсальный агент (может сам создавать других)

class RecursiveAgent(Node):
    def __init__(self, agent_id, task, memory, flow):
        self.agent_id = agent_id
        self.task = task
        self.memory = memory
        self.flow = flow

    def run(self, state, context):
        self.memory.log(self.agent_id, "user", self.task)

        messages = [{"role": m["role"], "content": m["content"]} for m in self.memory.get(self.agent_id)]
        messages.insert(0, {"role": "system", "content": "Ты агент, решающий задачи. Ты можешь создавать подагентов через функцию create_agent."})

        response = client.chat.completions.create(
            model="gpt-4o",
            messages=messages,
            tools=[{
                "type": "function",
                "function": {
                    "name": "create_agent",
                    "description": "Создай подагента",
                    "parameters": {
                        "type": "object",
                        "properties": {
                            "name": {"type": "string"},
                            "goal": {"type": "string"}
                        },
                        "required": ["name", "goal"]
                    }
                }
            }],
            tool_choice="auto"
        )

        msg = response.choices[0].message
        self.memory.log(self.agent_id, "assistant", msg.content or "[tool_call]")

        tool_calls = msg.tool_calls
        if tool_calls:
            for tool_call in tool_calls:
                args = tool_call.function.arguments
                new_id = args["name"] + "-" + str(uuid4())[:5]
                new_goal = args["goal"]

                self.memory.log(new_id, "system", f"Создан агент по задаче: {new_goal}")
                agent = RecursiveAgent(new_id, new_goal, self.memory, self.flow)
                self.flow.add_node(new_id, agent)
                self.flow.connect(self.agent_id, new_id)

                print(f"[+] Агент {new_id} создан: {new_goal}")

                # Рекурсивно запустить
                self.flow.run({})

        else:
            print(f"[=] Результат агента {self.agent_id}: {msg.content}")
            return {**state, "result": msg.content}

1. ReasoningCache: сохранение reasoning + прогресса

class ReasoningCache:
    def __init__(self):
        self.store = {}

    def log(self, agent_id, entry):
        self.store.setdefault(agent_id, []).append(entry)

    def get(self, agent_id):
        return self.store.get(agent_id, [])

    def mark_done(self, agent_id):
        self.store.setdefault(agent_id, []).append({"status": "done"})

    def is_done(self, agent_id):
        return any(e.get("status") == "done" for e in self.store.get(agent_id) or [])

2. AutoflowAgent: агент, использующий Assistant API

import asyncio
from openai import OpenAI

class AutoflowAgent:
    def __init__(self, client: OpenAI, assistant_id: str, agent_id: str, cache: ReasoningCache):
        self.client = client
        self.assistant_id = assistant_id
        self.agent_id = agent_id
        self.cache = cache

    async def run(self, input_text: str):
        if self.cache.is_done(self.agent_id):
            print(f"[skip] Agent {self.agent_id} уже завершен")
            return

        print(f"[run] Agent {self.agent_id}: {input_text}")
        thread = self.client.beta.threads.create()
        self.client.beta.threads.messages.create(thread_id=thread.id, role="user", content=input_text)
        run = self.client.beta.threads.runs.create(thread_id=thread.id, assistant_id=self.assistant_id)

        while run.status not in ("completed", "failed", "cancelled", "expired"):
            await asyncio.sleep(1)
            run = self.client.beta.threads.runs.retrieve(thread_id=thread.id, run_id=run.id)

        messages = self.client.beta.threads.messages.list(thread_id=thread.id).data
        for msg in reversed(messages):
            if msg.role == "assistant":
                content = msg.content[0].text.value
                print(f"[assistant] {content}")
                self.cache.log(self.agent_id, {"role": "assistant", "content": content})
                self.cache.mark_done(self.agent_id)
                return content

from aiohttp import web
import json

class MCPServer:
    def __init__(self, runtime: AutoflowRuntime):
        self.runtime = runtime
        self.app = web.Application()
        self.app.add_routes([web.post('/agent/task', self.handle_task)])

    async def handle_task(self, request):
        data = await request.json()
        task = data.get("task")
        if not task:
            return web.json_response({"error": "task is required"}, status=400)

        agent_id = self.runtime.add_agent("external", task)
        self.runtime.set_entrypoint(agent_id)

        # Запускаем (async)
        asyncio.create_task(self.runtime.run())

        return web.json_response({"agent_id": agent_id, "status": "started"})

    def run(self, host="0.0.0.0", port=8080):
        web.run_app(self.app, host=host, port=port)
